# 실제 스택 검증 도구

단위 테스트(목)가 **못 보는 것** — MySQL 교착·낙관적 잠금·연결 풀 고갈·DB 에 실제로 저장되는 값 — 을 실제 백엔드 jar + DB 로 확인한다.
11-22 에 이 도구들로 500 세 가지(같은 시나리오 동시 계산·동시 수정·최악 입력 부하)를 찾았고, 정차역 저장을 JDBC 배치로 바꿀 때 정답지 대조가 안전망이었다.

## 전제

- `docker compose up -d` (DB `railfeas-db`·Redis) — 시드를 고쳤으면 `down -v` 먼저(가입 계정·시나리오가 사라진다)
- `cd backend && ./mvnw package -DskipTests` — **jar 시각을 확인할 것**(`package` 는 조용히 실패한다). 이 도구는 `backend/target/railfeas-0.1.0.jar` 를 띄운다
- 저장소 루트의 `.env` (DB 접속·`JWT_SECRET`) — **값은 출력하지 않는다**
- 9090 포트가 비어 있어야 한다(`harness.py` 가 확인하고 멈춘다). Windows 전용 부분: 듣는 PID 조회(PowerShell)·`taskkill`
- 실행은 저장소 루트에서 `PYTHONUTF8=1 python tools/verify/<이름>.py`. 출력 파일은 `tools/verify/out/`(git 무시)

## 무엇을 언제

| 도구 | 하는 일 | 언제 돌리나 |
|---|---|---|
| `sweep.py` | 전국 대표 노선 31개 계산 → 오류·역 수·B/C 범위·경고 길이·시간 이상 + **서버 추천을 응답으로 독립 재계산해 대조** | 계산·추천 규칙, 기준값, 도로·해안선 자료, 의존성을 바꾼 뒤. 전후의 「서버 추천」 목록을 `diff` 하면 영향 범위가 나온다 |
| `fuzz.py` | 잘못되거나 극단적인 입력 약 50가지 → 5xx·연결 끊김·느린 응답 (플래그 0건이 정상) | 스프링 웹·시큐리티·검증을 바꾼 뒤(Boot 업그레이드), API 를 더한 뒤 |
| `concurrency.py` | ① 같은 시나리오 동시 계산 ② 긴 계산 여럿 + 그동안 가벼운 요청 지연 ③ 계산·수정·삭제 혼합. `--worst N`(최악 입력 N 개)·`--pool N`·`--debug-tx` | 트랜잭션·잠금·저장 방식·동시 실행 한도를 바꾼 뒤 |
| `oracle.py` | 노선 24개의 **저장된 응답 JSON 전체**를 만들어 전후 `cmp` | **영속성·계산 계층을 바꾸기 전에 먼저** 만들 것(엔티티 매핑·저장 방식·직렬화) |

`harness.py` 는 공통부다(서버 기동·정리·시험 계정). 새 시험을 더할 때 `with Server("접두사") as s:` 로 시작하면 서버·계정 정리와 포트 확인을 공짜로 얻는다.
자료 파일을 없는 경로로 가리켜 그 규칙을 끄는 실험(`Server("x", {"ROAD_FILE": "../data/build/__none__"})` — 서울~부산 B/C 0.69 → 0.56 의 원인을 가를 때 썼다)과
연결 풀 축소(`SPRING_DATASOURCE_HIKARI_MAXIMUM_POOL_SIZE`)도 같은 방식이다.

## 읽는 법

- 종료 코드 0 = 통과, 1 = 이상. `concurrency.py` 에서 **429 는 정상**이다(사용자당 계산 한도 2) — 500 과 서버 `ERROR` 로그가 0 이어야 한다.
- 정답지 대조(`oracle.py --compare a.json b.json`)는 **값이 바뀌지 않아야 하는 변경**에만 쓴다. 규칙·기준값을 일부러 바꿨다면 `sweep.py` 의 추천 목록 diff 를 본다.
- 측정한 시간은 **이 PC(Docker Desktop·8코어)** 기준이다. 절대값이 아니라 전후 비교로 읽을 것.

## 알려진 함정 (겪은 것)

- **윈도우 `java` 는 껍데기 → 진짜 JVM(자식) 구조**라 `Popen.terminate()` 로는 서버가 안 죽는다. 남은 서버가 같은 포트를 잡으면 뒤 시험이 앞 서버의 대답을 받는다(네 번이 전부 같은 값). `harness.py` 가 듣는 PID 를 직접 끈다.
- **브라우저는 한 주소에 연결을 6개까지만** 열어, 브라우저에서 동시 요청을 보내면 서버가 아니라 브라우저 대기열을 잰다. 이 도구는 파이썬 스레드로 직접 보낸다.
- 숨은 브라우저 창에서는 `requestAnimationFrame` 이 안 돈다(화면 측정은 `frontend/CLAUDE.md` 참고).
